# Aprendendo Go

Repositório destinado aos meus estudos da linguagem de programação **Go (Golang)**.

## Estrutura

```text
.
├── ambiente-de-estudos
│   └── Containerfile
└── README.md
```

### Ambiente de estudos

A pasta `ambiente-de-estudos` contém o `Containerfile` utilizado para criar o ambiente de desenvolvimento e estudos em Go.

O objetivo é manter o ambiente isolado e reproduzível, facilitando a configuração sem depender diretamente das ferramentas instaladas no sistema hospedeiro.

```text
ambiente-de-estudos/
└── Containerfile
```

Mais conteúdos, exemplos e exercícios serão adicionados ao repositório conforme os estudos avançarem. 🚀
